# Сайт массажного кабинета Александры

Одностраничный сайт `reborn-massage.ru` для согласования через GitHub Pages и публикации на Reg.ru.

## Что уже реализовано

- адаптивная версия для компьютеров, планшетов и телефонов;
- услуги с длительностью и ценой;
- объяснение первого визита и подхода мастера;
- реальные фотографии из материалов клиента;
- запись напрямую в Telegram;
- адрес, график, телефон, email и ссылка на маршрут;
- локальные шрифты и изображения без внешних CDN;
- без форм и аналитики; отзывы Яндекса загружаются только после явного согласия;
- статическая сборка, которую можно разместить на обычном хостинге.

## Локальный запуск

Требуется Node.js 22 и pnpm.

```bash
pnpm install
pnpm dev
```

Обычная статическая сборка:

```bash
pnpm build
```

Готовые файлы появятся в `dist/client`.

Индексируемая продакшен-сборка для `https://reborn-massage.ru`:

```bash
pnpm run build:production
pnpm run verify:release
```

## Согласование через GitHub Pages

В репозитории уже есть workflow `.github/workflows/deploy-pages.yml`.

1. Создайте репозиторий на GitHub и отправьте проект в ветку `main`.
2. В настройках репозитория откройте **Settings → Pages**.
3. В поле **Source** выберите **GitHub Actions**.
4. После завершения workflow ссылка появится в разделе Pages.

Команда `pnpm build:pages` делает сборку переносимой для адреса вида `username.github.io/repository/` и удаляет клиентский JavaScript, который этой странице не нужен.

## Публикация на Reg.ru

Для продакшена рекомендуется использовать ту же переносимую сборку:

```bash
pnpm build:pages
```

Содержимое `dist/client` нужно загрузить в корневую папку сайта на хостинге, обычно `public_html`. Файл `.htaccess` добавит безопасные заголовки и перенаправление на HTTPS при поддержке Apache.

Админка станет доступна по адресу `/admin/` после загрузки на хостинг с PHP 8.1 или новее. Её приватный конфиг должен лежать в `../private/admin-config.php` относительно `public_html`; в публичную сборку он намеренно не попадает.

Перед открытием сайта в поиске:

1. подтвердить окончательное название и имя мастера;
2. проверить HTTPS на `reborn-massage.ru`;
3. выполнить продакшен-сборку;
4. проверить ссылки Telegram, телефона, email и маршрута.

## Что нужно получить от клиента

- окончательное название практики;
- утверждённое написание имени мастера;
- ссылку на MAX, если она нужна;
- биографию, стаж, квалификацию и дипломы, если их решат публиковать;
- реальные отзывы с разрешением на публикацию;
- подтверждение формулировок и цен.

До получения этих материалов сайт не выдумывает опыт, отзывы, квалификацию или медицинские результаты.
